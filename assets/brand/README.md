# Ressources de marque Nexus

| Fichier | Usage |
| --- | --- |
| `original/nexus-planche-logo.png` | Planche de logo fournie par Studio Prism (référence, non modifiée) |
| `nexus-mark.svg` | Symbole « N » facetté en vectoriel, pour fonds clairs (interface, connexion) |
| `nexus-app-icon.svg` | Icône d'application sur fond bleu nuit (manifeste, favicon) |
| `nexus-mono.svg` | Version monochrome (`currentColor`) |
| `nexus-icon-light.svg` | Icône claire, symbole bleu nuit |
| `favicon.svg` | Copie de l'icône d'application |

Les SVG sont une **vectorisation fidèle** de la planche : même construction (deux montants et une diagonale en ruban, facettes), mêmes nuances de bleu, cyan et turquoise. Seul ajustement : pas de halo lumineux sur fond clair, pour la lisibilité (le halo reste sur l'écran de connexion, fond bleu nuit). Le mot-symbole NEXUS est composé en Sora, lettres très espacées, proche de la planche (sa police exacte n'est pas fournie).

Pour remplacer par des fichiers officiels (SVG d'origine), garder les mêmes noms de fichiers.
